# Лабораторная работа 1: Основы ООП - "Ходячий"

## Описание проекта
Проект реализует симуляцию движения людей с использованием объектно-ориентированного программирования на Kotlin. Моделируется случайное блуждание объектов в двумерном пространстве.

## Модель движения: Random Walk (Случайное блуждание)

### Математическая формула
Движение реализовано по модели Random Walk в картезианской системе координат:

x(t+1) = x(t) + Δx × speed
y(t+1) = y(t) + Δy × speed



### Обозначения
 x(t), y(t) - текущие координаты объекта в момент времени t
 x(t+1), y(t+1) - новые координаты объекта в момент времени t+1
 Δx, Δy - случайные значения в диапазоне [-1, 1]
 speed - скорость движения объекта

### Реализация в коде
fun move() {
    x += (Math.random() * 2 - 1) * speed
    y += (Math.random() * 2 - 1) * speed
}

Генерация случайного направления
text

Δx = Math.random() × 2 - 1
Δy = Math.random() × 2 - 1

Диапазоны значений
    Math.random() ∈ [0.0, 1.0]
    Math.random() × 2 - 1 ∈ [-1.0, 1.0]

Класс Human
Свойства
    fullName: String - ФИО человека
    age: Int - возраст
    speed: Double - текущая скорость движения
    x: Double, y: Double - координаты в пространстве

Методы
    Конструкторы: первичный (со всеми параметрами) и вторичный (со значениями по умолчанию)
    Геттеры и сеттеры: для всех свойств класса
    move(): основной метод движения, реализующий Random Walk

Пример использования

val person = Human("Иванов Иван", 25, 2.5)
person.move() // совершает случайное перемещение

Симуляция движения
Параметры симуляции
    Количество объектов: 4 человека
    Время симуляции: 10 секунд
    Интервал между шагами: 500 мс

Логика работы
    Создается массив объектов Human с разными параметрами
    Запускается цикл на заданное время симуляции
    На каждой итерации все объекты совершают движение
    Выводятся текущие координаты каждого объекта

Особенности реализации
    Использование вторичного конструктора для установки значений по умолчанию
    Форматирование вывода координат до 2 знаков после запятой
    Задержка между шагами для наглядности симуляции
    Случайный характер движения каждого объекта
