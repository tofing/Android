 Лабораторная работа 2: Наследование

## Добавленные изменения

### Новый класс Driver
Создан класс-наследник `Driver`, который наследует свойства и методы от базового класса `Human`.

#### Наследуемые свойства:
- `fullName` - ФИО водителя
- `age` - возраст
- `speed` - скорость движения
- `x`, `y` - координаты в пространстве

#### Дополнительные свойства:
- `carModel: String` - модель автомобиля
- `directionX: Double = 1.0` - направление по оси X
- `directionY: Double = 1.0` - направление по оси Y

### Переопределение метода move()
Класс `Driver` переопределяет метод `move()` для реализации прямолинейного движения:

#### Математическая модель прямолинейного движения:

x(t+1) = x(t) + directionX × speed
y(t+1) = y(t) + directionY × speed

#### Реализация в коде:
```kotlin
override fun move() {
    x += directionX * speed
    y += directionY * speed
}
